# TikTok Marketing Skills

Distilled from *The Real Guide to Growing on TikTok: What Makes People Watch, Engage, and Follow — And How to Make It Happen (Guides to Success)*.

## Core Thesis

Growth on TikTok is a behavioral loop: **hook attention fast, deliver a clear payoff, and trigger interaction signals the algorithm can amplify.**

## The 10 Skills

| # | Skill | Core Focus |
|---|-------|------------|
| 1 | [Hook Engineering](01-hook-engineering.md) | First-second attention capture — interrupt the scroll |
| 2 | [Retention Structuring](02-retention-structuring.md) | Watch-time design — keep viewers to the end |
| 3 | [Value Compression](03-value-compression.md) | High signal per second — deliver clear payoff fast |
| 4 | [Algorithm Signaling](04-algorithm-signaling.md) | Design for completion, rewatch, and engagement velocity |
| 5 | [Niche Positioning](05-niche-positioning.md) | Become recognizable for a specific value domain |
| 6 | [Format Replication](06-format-replication.md) | Treat content as experiments — create, measure, iterate |
| 7 | [Psychological Engagement](07-psychological-engagement.md) | Prompt interaction through human tendencies |
| 8 | [Authentic Presence](08-authentic-presence.md) | Reduce perceived distance between creator and viewer |
| 9 | [Consistency Signal](09-consistency-signal.md) | Post regularly to train both algorithm and audience |
| 10 | [Audience-First Framing](10-audience-first-framing.md) | Start from viewer motivation, not creator expression |

## Condensed Growth Formula

```
TikTok Growth = Hook Design + Retention Structure + Value Clarity + Behavioral Signaling
```

If any one element is weak, distribution plateaus.

## Strategic Takeaway

Grow on TikTok by **engineering viewer behavior** — not just creating content — so the platform observes sustained attention, repeated viewing, and active participation.
