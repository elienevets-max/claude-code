## Related Content From Other Playbooks

These docs contain principles that directly apply to TikTok execution. Use them alongside the TikTok-specific strategies above.

### Marketing & Psychology

| Doc | What's Relevant to TikTok |
|-----|--------------------------|
| [Marketing Psychology](../business/marketing-psychology.md) | **Hook into the 5 core human drives** — every TikTok hook should target Acquire, Bond, Learn, Defend, or Feel. **Lead with benefits, not features** — applies directly to TikTok product demos. **Counter-signaling** — stand out in a saturated feed by being the polar opposite of what's expected. **The "Piss Off 80%" rule** — polarizing content outperforms vanilla on TikTok's algorithm. |
| [Entrepreneurship Playbook](../entrepreneurship/entrepreneurship-playbook.md) | **Sell the sizzle, not the steak** (Section: How to Sell) — TikTok hooks work when they sell the outcome, not the product. **The Staircase Philosophy** (Section: How to Market) — do something wild that people talk about, then build a PR wave around it. **Marketing should be fun** — only use TikTok if you enjoy creating on it (or build a creator community to do it for you). |
